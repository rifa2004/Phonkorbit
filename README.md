# PhonkOrbit (v1.0)

A desktop-first static page for a phonk music platform. Built with raw HTML5 and CSS3.

## Live Demo
👉 [https://lively-brioche-4f63d1.netlify.app/]

## What I built

- Top navigation: brand, search bar, premium link, notifications, and profile button.
- Left sidebar: main navigation, library section, playlists, and a premium card.
- Main area: hero section, trending row, and a Brazilian phonk grid.

(Right sidebar and bottom music player will come in later versions.)

## HTML concepts used

- Boilerplate setup (lang, charset, viewport, title).
- Semantic tags: header, nav, aside, main, section, article, form, search.

## CSS concepts used

- Layout: Flexbox for the top bar and sidebar items. Grid for the Brazilian phonk cards.
- Box sizing: global `box-sizing: border-box` reset so padding doesn't break outer sizes.
- Positioning: `relative` / `absolute` to place play buttons over album images.
- Styling: hover states with scale and opacity, `border-radius`, and `object-fit: cover` for images.
